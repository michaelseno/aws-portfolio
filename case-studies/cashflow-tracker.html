CashFlow Tracker — TestFlight Beta Proof Page

CashFlow Tracker is a private-beta personal finance mobile app with a TestFlight build. It keeps budgeting, recurring entries, savings progress, and account visibility usable on device without a live backend.

Product Problem

  • Everyday money tracking is easy to abandon when the workflow is slow or connectivity-dependent.
  • Budgeting tools often make recurring bills, savings, and transaction review feel heavier than they need to be.
  • For this scope, the priority is practical on-device usability rather than cloud sync.

Mobile Workflow Proof

  • Onboarding collects accounts, recurring income, bills, and savings goals before the dashboard loads.
  • Dashboard surfaces projected vs. actual spend, savings progress, transaction history, and quick actions.
  • Recurring flows support bill payments, salary logging, savings transfers, and account balance updates.

Beta Status Proof

  • Current portfolio framing is private beta / TestFlight, not public app-store availability.
  • The shipped proof here reflects a real beta state without exposing private distribution links.
  • Demo or walkthrough access can be shared on request instead of implying open public access.

Offline Architecture Proof

  • React Native (Expo) client persists data locally with SQLite for offline-first execution.
  • Local auth uses Secure Store with optional biometric sign-in support.
  • The FastAPI backend remains future-facing in the repo, but the current mobile app does not depend on it.

Implementation Evidence

  • Frontend package scripts include lint, typecheck, Vitest, and bundled verify flow.
  • Repo documentation explicitly states the app runs entirely offline on device.
  • Feature inventory in the source docs covers onboarding, dashboard, recurring flows, savings tracking, history, and account management.

Proof and Scope Clarity

  • Public-safe proof for this portfolio phase is documentation-based because the TestFlight build is private beta rather than openly distributed.
  • Current framing is TestFlight beta / private-beta mobile product, not a launched cloud-synced finance platform.
  • The optional backend is accurately treated as future sync work, not current app dependency.
